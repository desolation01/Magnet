# Asset Licenses — Magnet Mayhem

No third-party assets are used. All geometry is procedural and all audio is synthesized at runtime.

- Models: none. Characters, magnets, platforms and props are built from Babylon.js mesh primitives in code.
- Textures: none. The only texture (the particle sprite) is drawn at runtime with a canvas gradient.
- Animations: none. All character animation is procedural.
- Audio and music: none. Every sound effect is generated with the Web Audio API. There is no music.
- Fonts: the system font stack only. No web fonts are loaded.
